--- S5a：首次 npm run build 失败（重点） ---
PS> npm run build
（构建依次进入 chord、tui、telemetry、ai）
ai 包报错：
  src/providers/kimi-coding.ts(5,36): error TS2307: Cannot find module './kimi-coding.models.ts'
  src/providers/opencode-go.ts(13,3): error TS2322: Type '...' is not assignable to type 'readonly Model<...>[]'
    Type '"google-generative-ai"' is not assignable to type '"anthropic-messages" | "openai-completions" | "openai-responses"'
npm error Lifecycle script `build:offline` failed with error
npm error code 1

原因：generate-models 联网拉到更新的模型目录，删除了源码仍引用的 kimi-coding shard，
      并引入本版本源码不支持的 api 类型（gemini-4-argon）。

解决：
1) git checkout -- packages/ai/src/providers/kimi-coding.models.ts packages/ai/src/models.generated.ts
2) 从 npm @earendil-works/pi-ai@0.85.1 提取 dist/providers/data（40 个文件）到 src/providers/data
3) node scripts/check-model-data.ts → "Generated model data is valid."
4) npm run build:offline
